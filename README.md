# 트루로그 (TrueLog)

> 차에 이상한 순간이 왔을 때, 그 순간을 운전자 대신 기억해 주는 차량용 앱

Pleos Connect용 Android Automotive 앱입니다. 차량이 보내는 신호를 상시 5분 동안 기억하다가,
이상한 순간이 오면 전후 30초를 잠금 저장하고, 정비소에서 그대로 보여 줄 수 있는 리포트로 만듭니다.

- 버전: v0.5.0 (개발 중)
- 대상: Pleos Connect Emulator v2.1.0 이상 (API 34)
- 언어: Kotlin · Jetpack Compose

## 무엇을 하나요

| 단계 | 내용 |
|---|---|
| 기억 | 속도·기어·브레이크·조향각·배터리 잔량을 0.1초마다 최근 5분만 보관 (평소에는 계속 덮어씀) |
| 잠금 | 아래 순간이 오면 전후 30초를 저장하고 음성과 시스템 알림으로 "기억했어요"라고 알림 |
| 확인 | 정차 중에만 기록 상세 확인 · 재현 조건 · 최근 14일 반복 패턴 · 그래프 |
| 전달 | 운전자가 공유 범위를 직접 고른 뒤 QR → 휴대폰 리포트(PDF 저장·공유) |

**기록이 남는 순간**
- 출력 제한 경고 신호 (현재 에뮬레이터에서 신호를 만들 수 없어 데모용 시뮬레이션으로 재현, 화면·기록에 "시뮬레이션" 표기)
- 비상등 켜짐 (권한 제약으로 제조사 연계 시 제공)
- 급제동 (브레이크 입력 + 1초 안에 15km/h 이상 감속)
- 배터리 20% 미만
- 운전자가 정차 후 "방금 상황 저장"

## 설계 원칙

- **주행 중 터치 요구 0회.** 주행 중에는 음성과 시스템 알림만, 상세 화면은 정차 중에만 엽니다.
- **공개 API만 사용.** Pleos Vehicle SDK 2.3.2와 Android 표준 차량 속성 중 일반 앱이 받을 수 있는 권한만 씁니다. 제어(CONTROL_*)·비공개(PRIVATE_*) 권한은 쓰지 않습니다.
- **원본은 차 안에.** 리포트는 서버 없이 링크(QR) 안에 담겨 전달되며, 운전자가 고른 항목만 포함됩니다. 위치는 기본 제외입니다.
- **원인을 추측하지 않습니다.** 리포트는 "언제·어떤 조건에서" 일어났는지만 보여 주고, 진단은 정비사의 진단기 확인에 맡깁니다.

## 기록 확인 방식

각 기록은 저장할 때 SHA-256 값을 만들고 앞 기록의 값과 사슬처럼 잇습니다.
나중에 다시 계산한 값이 같으면 "저장 이후 바뀌지 않았다"는 뜻입니다.
이 방식은 변경 여부를 확인할 뿐 변경 자체를 막지는 않습니다.

> 트루로그의 기록은 운전자 측 참고 기록입니다. 공식 사고 기록(EDR)이나 고장 원인 진단을 대신하지 않으며, 차량 계기판과 제조사 안내가 우선합니다.

## 실행 방법

1. Android Studio(JDK 17 이상, Gradle JDK 21 권장)에서 이 폴더를 엽니다.
2. Device Manager에서 Pleos Connect Emulator(v2.1.0 이상)를 켭니다.
3. ▶ Run → 첫 실행 시 속도·에너지·알림 권한을 허용합니다.
4. 음성 파일이 없다면 Windows PowerShell에서 `tools/make_voice.ps1`을 실행합니다. (에뮬레이터에 TTS 엔진이 없을 때 쓰는 대체 음성)

## 테스트 (Virtual Console)

```
adb forward tcp:8088 tcp:8088
```
브라우저에서 `http://127.0.0.1:8088/` 을 엽니다.

- 기어 D + 가속 → 속도·기어 변화 확인
- 주행 중 브레이크 길게 → "급제동" 기록 + 음성·알림
- Energy > Battery SOC 50% → 15% → "배터리 20% 미만" 기록
- 기어 P → 메인에 "정차했어요" + 기록 보기 → 리포트 보내기 → QR

## 폴더 구조

```
app/src/main/java/app/truelog/
  signals/   차량 신호 수집 (Pleos SDK · Android 차량 속성)
  record/    5분 버퍼 · 잠금 저장 · 해시 체인
  voice/     음성 안내
  notify/    시스템 알림
  report/    리포트 링크·QR 생성
  ui/        화면 (Compose)
docs/report.html   휴대폰 리포트 뷰어 (GitHub Pages)
tools/             음성 파일 생성 스크립트
apk/               제출용 release APK
```
