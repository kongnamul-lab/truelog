# 트루로그 (TrueLog)

> 말하지 못한 증상까지, 고쳐질 때까지 기억하는 차.

Pleos Connect용 Android Automotive 앱입니다. 차량 신호를 최근 5분 동안 계속 기억하다가, 이상한 순간이 오면
앞뒤 30초를 잠금 저장하고 운전자의 한마디를 함께 남깁니다. 같은 일이 반복되면 겹치는 조건(재현 레시피)을 정리하고,
정비소에서는 QR 한 번으로 정비사 휴대폰에 리포트를 보여 줍니다.

| 항목 | 내용 |
|---|---|
| 앱 이름 | 트루로그 (TrueLog) · 패키지 `app.truelog` |
| 버전 | v0.9.1 |
| 제출용 APK | [`apk/TrueLog_TrueLog_release.apk`](apk/) |
| 휴대폰 리포트 예시 | https://kongnamul-lab.github.io/truelog/report.html |
| 테스트 환경 | Pleos Connect Emulator v2.1.0 (Android 14, API 34) · Windows 11 · Android Studio |
| 언어·UI | Kotlin · Jetpack Compose |

## 사용한 Pleos SDK

| SDK | 버전 | 쓰는 곳 |
|---|---|---|
| Vehicle | 2.3.2 | 브레이크·조향각·배터리 잔량·출력 제한 경고 수신 (+ Android 표준 속성으로 속도·기어·주행 가능 거리) |
| TextToSpeech | 3.3.1 | 주행 중 안내 음성 (ON_DEVICE 모드) |
| SpeechToText | 3.3.1 | 운전자 한마디를 문장으로 변환 (ON_DEVICE 모드, 앱이 녹음한 소리를 `sendAudio()`로 전달) |

- 음성 SDK는 ON_DEVICE 모드만 씁니다. 네트워크와 앱 등록(클라이언트 시크릿)이 필요 없고, 운전자의 말이 차 밖으로 나가지 않습니다.
- SDK를 쓸 수 없는 환경에서는 자동으로 대체합니다. 안내 음성은 앱에 넣은 녹음 음성(`res/raw`)으로, 한마디는 차 안 음성 메모로 남깁니다.
- 공개 권한만 씁니다. 제어(`CONTROL_*`)·비공개(`PRIVATE_*`) 권한은 쓰지 않습니다.

## 무엇을 하나요

| 단계 | 내용 |
|---|---|
| 기억 | 속도·기어·브레이크·조향각·배터리를 0.1초마다 최근 5분만 보관 (평소에는 계속 덮어씀) |
| 잠금 | 아래 순간이 오면 앞뒤 30초를 저장하고 음성·시스템 알림으로 "기억했어요"라고 알림 |
| 한마디 | "삐" 소리 뒤 8초 동안 운전자의 말을 음성 메모로 남기고 문장으로 바꿈 (첫 실행 때 운전자가 켤 때만) |
| 재현 레시피 | 같은 종류 기록이 2번 이상이면 속도 구간·조향·배터리 구간·기어의 공통 조건만 정리 (원인 추측 없음) |
| 전달 | 정차 중에 운전자가 공유 범위를 고른 뒤 QR → 휴대폰 리포트 (PDF 저장·공유) |

**기록이 남는 순간**
- 출력 제한 경고 신호 (에뮬레이터에서는 이 신호를 만들 수 없어 앱 안의 데모용 시뮬레이션으로 재현하고, 화면·기록·리포트에 "시뮬레이션"으로 표기)
- 급제동 (브레이크 입력 + 1초 안에 15km/h 이상 감속)
- 배터리 20% 미만
- 운전자가 정차 후 "방금 상황 저장"

## 실행 방법

1. Android Studio(JDK 17 이상)에서 이 폴더를 엽니다. Pleos Maven 저장소는 `settings.gradle.kts`에 등록돼 있습니다.
2. Device Manager에서 Pleos Connect Emulator(v2.1.0 이상)를 켭니다.
3. ▶ Run 하거나, 빌드된 APK를 설치합니다.
   ```
   adb install -r apk/TrueLog_TrueLog_release.apk
   ```
4. 첫 실행 때 속도·에너지·알림 권한을 허용하고, 한마디 기능을 쓸지 고릅니다(기본 꺼짐, 켜면 마이크 권한 요청).

## 필요한 설정

- 한마디 테스트: 에뮬레이터 Extended controls → Microphone → "Virtual microphone uses host audio input"을 켜고, PC 마이크 음소거를 해제합니다.
- 별도의 API 키나 클라이언트 시크릿은 필요 없습니다.
- 에뮬레이터를 콜드 부팅한 뒤에는 Virtual Console 연결을 다시 해야 합니다.

## 테스트 (Virtual Console)

```
adb forward tcp:8088 tcp:8088
```
브라우저에서 `http://127.0.0.1:8088/`을 엽니다.

1. 기어 D + 가속 → 앱의 속도·기어 변화 확인
2. 주행 중 브레이크 길게 → "급제동" 기록 + 음성·알림
3. Battery SOC 50% → 15% → "배터리 20% 미만" 기록
4. 앱 "개발 정보" → "출력 제한 경고 시뮬레이션" → 20초 뒤 잠금 → 안내 음성 → "삐" 뒤 한마디
5. 기어 P → "정차했어요" → 기록 보기 → 리포트 보내기 → QR을 휴대폰으로 스캔

## 기록 확인 방식

각 기록을 저장할 때 SHA-256 값을 만들고 앞 기록의 값과 사슬처럼 잇습니다.
나중에 다시 계산한 값이 같으면 "저장 이후 바뀌지 않았다"는 뜻입니다. 이 방식은 변경 여부를 확인할 뿐 변경 자체를 막지는 않습니다.

> 트루로그의 기록은 운전자 측 참고 기록입니다. 공식 사고 기록(EDR)이나 고장 원인 판정을 대신하지 않으며, 차량 계기판과 제조사 안내가 우선합니다.

## 개인정보

- 원본은 차 안에만 저장합니다. 리포트는 서버를 거치지 않고 링크(QR) 안에 담기며, 보기 페이지가 24시간 뒤 표시를 멈춥니다.
- 위치는 기본 제외, 공유할 항목은 매번 운전자가 고릅니다.
- 운전 중 생긴 기록은 90일 뒤 자동 정리합니다. 모든 기록은 정차 중 언제든 지울 수 있습니다.

## 폴더 구조

```
app/src/main/java/app/truelog/
  PleosVoice.kt  안내 음성·한마디 듣기 (Pleos TTS·STT SDK, 대체 경로 포함)
  signals/   차량 신호 수집 (Pleos Vehicle SDK · Android 차량 속성)
  record/    5분 버퍼 · 잠금 저장 · 해시 체인 · 재현 레시피
  voice/     대체 음성 경로 (녹음 안내 음성 · 음성 메모)
  notify/    시스템 알림
  report/    리포트 링크·QR 생성
  ui/        화면 (Compose)
docs/report.html   휴대폰 리포트 보기 페이지 (GitHub Pages)
tools/             대체 안내 음성 생성 스크립트
apk/               제출용 release APK
```
